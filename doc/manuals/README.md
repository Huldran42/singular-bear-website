# Sources des manuels

Les manuels affichés sur le site sont structurés dans `src/lib/manuals.ts`. Ce dossier peut accueillir les versions longues en Markdown, les PDF sources et les notes de version destinées au support.

Les informations de prix, de version et de compatibilité proviennent des pages officielles Unity Asset Store. Avant une publication, comparer ces données avec la dernière version du package.
